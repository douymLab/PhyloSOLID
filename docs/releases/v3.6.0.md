# Version 3.6.0

## Highlights

- **Pre-QC/post-QC comparison:** Export the selected tree before and after Step 8 quality control.
- **Aligned mode safeguards:** Consistent zero-Omega handling, fallback priority and deterministic CV selection.
- **Resolution backoff:** Conflict-guided auto-resolution backoff for scRNA, SpaceTracer and binary-matrix; scDNA retains fixed resolution `0.1` by default.
- **Updated examples and guides:** Three refreshed demos, a shorter README and a complete parameter reference.

---

## What's New

### Tree export

- `phylo/` contains the Step 8 result; `phylo_unpruned/` contains the Step 7 pre-QC snapshot. Both remove all-zero inferred matrix rows/columns and collapse corresponding tree nodes.
- Restore the pre-QC snapshot if QC leaves no usable tree, explicitly marking `phylo/` as `pre_fallback`.
- Add `output_stage.json` and `README_phylo.txt` to identify result stages and summarize output metadata.

### Resolution and CV selection

- Add `--resolution_backoff_threshold` (default `0.10`) and `--disable_resolution_backoff` to all four direct tree-building entry points. Fixed resolution takes precedence.
- Search downward on the same graph within fixed bounds; retain the original auto partition if no candidate meets the budget. Save decision and trajectory files for inspection.
- Prefer usable post-QC candidates, handle zero-Omega scores safely, and break CV ties deterministically.
- Include ROOT-assigned mutations consistently in pre-QC/CV scoring and exports.

### Demos and documentation

- Refresh scRNA, scDNA and binary-matrix tree-building results and circos plots, reusing existing upstream feature/tree-input files.
- Package both result bundles and stage metadata under `demo/*/expected_output/`. Post-QC examples: scRNA **352 × 17**, scDNA **22 × 78**, binary-matrix **8 × 19** (cells × mutations).
- Move detailed setup, usage and troubleshooting into `docs/`; document mode-specific defaults and currently inactive parameters.

### Bug Fixes

- Fix pruning-ratio division by zero and inconsistent zero/zero handling.
- Prevent pre-QC fallbacks from being labeled confident or preferred over usable post-QC results.
- Correct outdated threshold text and preserve inferred matrix export when optional conflict-free plotting does not pass.

### Breaking Changes

- **`phylo_unpruned/` now means pre-QC:** It no longer contains the post-QC tree before all-zero cleanup. Regenerate existing results for the new layout.
- ROOT-consistent scoring, pruning safeguards and enabled auto-resolution backoff can change Omega values, selected CVs and final trees relative to v3.5.0.

---

## Notes

- Validated with **20 regression tests**, pruning integration checks, three demo tree-building/visualization runs, and documentation checks. BAM preprocessing was not repeated for the demo refresh.
- Backoff and pruning thresholds are empirical guards, not confidence probabilities or estimated doublet rates.
- CV/backoff controls are available through direct Python entry points; they are not automatically forwarded by the pipeline CLI. scDNA backoff remains inactive with its default fixed resolution.
- Local runs, logs, caches and machine-specific configuration remain ignored; circos uses a separate visualization environment.
- See the [README](https://github.com/douymLab/PhyloSOLID/blob/main/README.md), [parameter reference](https://github.com/douymLab/PhyloSOLID/blob/main/docs/parameters.md) and [output-stage guide](https://github.com/douymLab/PhyloSOLID/blob/main/docs/phylo_output_stages.md) for details.
