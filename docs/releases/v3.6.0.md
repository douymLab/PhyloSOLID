# PhyloSOLID v3.6.0

This release aligns pruning safeguards across modes and preserves both pre-QC and post-QC results for the selected tree.

- Align resolution-backoff options across scRNA, SpaceTracer, binary matrix and scDNA; preserve scDNA fixed resolution 0.1 by default.
- Handle zero-discordance scores consistently and prefer usable post-QC candidates, with deterministic CV tie-breaking.
- Write the cleaned Step 7 pre-QC snapshot to phylo_unpruned/ and the cleaned Step 8 result to phylo/. Mark empty-final fallback as pre_fallback.
- Include ROOT-assigned mutations consistently in scoring and exports.
- Refresh all three packaged demo snapshots, plots, stage metadata and CV summaries.
- Reorganize README and add a full parameter reference with implementation caveats.

## Compatibility notes

phylo_unpruned/ now means before Step 8 QC, rather than before export cleanup. Both bundles remove all-zero inferred matrix rows and columns. Existing result directories must be regenerated. ROOT-consistent scoring can change Omega and selected CVs. Some declared algorithm fields remain inactive; see docs/parameters.md. A backoff conflict budget is an empirical guard, not a doublet probability.

## Validation

20 regression tests plus pruning integration checks; three demo tree-building and visualization runs; parameter/CLI inventory and documentation link checks. Full BAM preprocessing was reused for the demo refresh.
